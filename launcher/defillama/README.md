# Surco DeFiLlama Adapter Draft

Ready to submit as a PR to `https://github.com/DefiLlama/DefiLlama-Adapters`.

## How to submit (free)
1. Fork `DefiLlama/DefiLlama-Adapters`.
2. Copy `index.js` here to `projects/surco/index.js` in your fork.
3. Test locally inside the fork:
   ```bash
   npm install
   node test.js projects/surco/index.js
   ```
4. Open a PR with:
   - **Name**: Surco
   - **Website**: `https://surcofi.com`
   - **Twitter**: `https://x.com/chirpfi`
   - **Category**: Launchpad / Yield
   - **Chain**: Base
   - **Description**: A leviathan-free ecosystem built on Pinto and Base. Flagship Chirp (one-sided Pinto Silo book), permissionless coin launcher whose trade fees buy Pinto into the Silo, and Collective Silo + veChirp NFT gauge.
   - **Logo**: `chirp/web/public/chirp-icon-512.png` (or Surco mark)
